### Избранные проекты

#### **BETAIGO — AI Sports Analytics**  
*ноябрь 2025 – июнь 2026*

Мобильное приложение (React Native) + Web-версия (Next.js) для AI-аналитики спортивных матчей.  
Сервис анализирует матчи по десяткам параметров: форма команд, история личных встреч, статистика дома/выезда, травмы и составы, тренды голов и другие ключевые метрики — превращая данные в прогнозы с помощью LLM-моделей.

**Мой вклад:**  
- Разработал фронтенд для **Web** (Next.js) и **Mobile** (React Native) версий приложения.  
- Спроектировал архитектуру модуля для работы с API, обеспечив единый интерфейс для получения данных и прогнозов.  
- Интегрировал тестирование: писал unit-тесты (Jest) и e2e-тесты для критических пользовательских сценариев.  
- Разработал адаптивные и нативные интерфейсы для отображения сложной статистики и прогнозов.

**Стек:** React Native, Next.js, TypeScript, Jest, E2E-тестирование, LLM-интеграция, REST API.

#### **git-warden** — CLI Guard для Git  

*Легковесная обёртка вокруг Git, которая запрашивает подтверждение перед выполнением команд `commit`, `push` и `checkout` после длительного простоя терминала.*

**Проблема:** после долгого перерыва легко забыть синхронизировать ветку перед коммитом или пушем.  
**Решение:** инструмент отслеживает время последней активности в терминале и при превышении порога (по умолчанию 1 час) спрашивает: *«Вы уверены?»*.

**Ключевые возможности:**
- Отслеживает время простоя через `~/.git-activity-guard-timestamp`
- Поддерживает `push`, `commit`, `checkout` — для остальных команд работает как обычный `git`
- Настраиваемый порог ожидания (через JSON-конфиг или переменную окружения)
- Команда `git-warden init` создаёт хуки `pre-commit`, `pre-push`, `post-checkout` для защиты всей команды
- Можно обернуть стандартный `git` через shell-функцию — тогда защита работает автоматически

**Стек:** Node.js, CLI, Git Hooks

🔗 **Репозиторий:** [github.com/maofao/git-warden](https://github.com/maofao/git-warden)  
📦 **npm:** `npm install --save-dev git-warden` или `npm install --global git-warden
